# Семантическое ядро — ПСМ-Монолит

Кластеризация запросов по посадочным страницам. Регион продвижения — **Московская
область / Подмосковье**. Значения `title`/`description`/`keywords` заданы в
`config/seo.php` и автоматически подставляются в `<head>` каждой страницы.

Приоритеты частотности условны (ВЧ — высокочастотный, СЧ — среднечастотный,
НЧ — низкочастотный/гео) и служат для расстановки акцентов в текстах.

## Техническая оптимизация (реализовано)
- Уникальные `title` и `meta description` на каждой странице (`config/seo.php`).
- По одному `<h1>` на страницу; секционные заголовки — `<h2>`.
- Язык документа `lang="ru"`, канонические ссылки, Open Graph.
- Микроразметка Schema.org (LocalBusiness, WebSite, BreadcrumbList) — `partials/schema.blade.php`.
- `sitemap.xml` (`/sitemap.xml`) и HTML-карта сайта (`/sitemap`).
- `robots.txt` с директивой `Sitemap` и закрытой админкой.

## Что стоит развивать дальше
- Отдельные посадочные под гео-запросы (доставка бетона в конкретные города).
- Отдельные страницы под марки (М200/М300/М400) с ценами и применением.
- FAQ-блок с микроразметкой `FAQPage`.
- Наполнение объектов реальными фото (alt с ключами) и текстовыми описаниями.
- Блог/статьи под информационные запросы («какая марка бетона для фундамента»).
